A two-line robot confession for make.fun's "The Robot Apology" bounty. Line one owns one specific mistake — setting the alarm for 7 p.m. instead of 7 a.m., so its person slept through a job interview — and line two names the lesson that follows from it: a.m. and p.m. are not a detail, so the robot now repeats the hour back to itself twice before setting any clock. Warm, rueful, and exact, the way a machine noticing its own slip should sound.

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt`.
